# Configs

Personal dotfiles for macOS and Linux. The repository lives at `~/configs`.

`./AGENTS.md` defines repository instructions. `agents/AGENTS.md` defines global user instructions.

Keep `CLAUDE.md` as the single `@AGENTS.md` import.

## Repository requirements

- Support macOS and Linux where practical.
- Run changed scripts against realistic input before documenting their behavior.
- Preserve committed binary and generated files, including `.icns` files and `lazy-lock.json`.

## Task-specific context

- For agent configuration changes, read `agents/reference/deployment.md` before editing.
- For formatter configuration changes, read `agents/reference/formatting.md` before editing.
- For tmux changes, read `tmux/README.md` before editing.
- For Neovim changes, read `nvim/README.md` before editing.
- For worktree or Zsh linking changes, read `zsh/README.md` before editing.
