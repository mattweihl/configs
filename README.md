# My configs

Personal configuration files for macOS and Linux.

The repository lives at `~/configs`.

## Deployment

- `nvim/` links to `~/.config/nvim/`.
- `lazygit/` links to the platform-specific Lazygit configuration path.
- `tmux/tmux.conf` loads from a `~/.tmux.conf` wrapper.
- `tmux/tmux-powerline/` links to `~/.config/tmux-powerline/`.
- `zsh/config.zsh` loads from a `~/.zshrc` wrapper.
- `glow/` links to the platform-specific Glow configuration path.

Run `link-agentic-configs` to deploy agent configuration.

See `agents/reference/deployment.md` for the complete agent deployment map.
